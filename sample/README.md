# Sample workspace

Welcome to the **MdExplorer** sample folder. Open this folder in MdExplorer (`Ctrl+O`) to try the app.

## What is in here

| Folder | Contents |
|---|---|
| [`guide/`](guide/getting-started.md) | How to use MdExplorer |
| [`notes/`](notes/ideas.md) | Notes with YAML front matter |
| [`reference/`](reference/markdown-showcase.md) | Markdown features and an API reference |
| `assets/`, `data/` | Non-Markdown files (switch the tree to **All files** to see them) |

## Things to try

1. Click a link below to open another document in a new tab. The folder tree is not touched.
   - [Getting started](guide/getting-started.md)
   - [Keyboard shortcuts](guide/keyboard-shortcuts.md)
   - [Meeting notes](notes/meeting-2026-10-13.md)
   - [API endpoints](reference/api/endpoints.md)
2. Press `Ctrl+Shift+F` and search for `search` (turn on **Also search file contents**).
3. Press `Ctrl+,` and switch the **Interface theme** and **Document theme**.
4. Click **MD only** to show all files, including the binary ones in `data/`.

> Tip: external links such as [the MdExplorer repository](https://github.com/czhou-perosnal-share/mdexplorer) open in your browser.
