# Getting started

MdExplorer is a fast browser for folders full of Markdown.

## Open a folder

- Press `Ctrl+O`, or click **Open Folder** in the toolbar.
- Or launch it with a folder argument:

```bash
mdexplorer ./sample
```

## Browse

The **Explorer** loads a folder only when you expand it, so even very large trees open instantly.

## Search

Use the **Search** icon in the activity bar. The search runs in the background: you can keep reading and switching tabs while results stream in.
