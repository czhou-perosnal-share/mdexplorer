# Keyboard shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl+O` | Open folder |
| `Ctrl+,` | Settings |
| `Ctrl+Shift+F` | Search files |
| `Ctrl+Shift+E` | Tab switcher |
| `Ctrl+Tab` | Next tab |
| `Ctrl+W` | Close tab |
| `F5` | Refresh the tree |
| `j` / `k` | Scroll down / up |

See also: [Getting started](getting-started.md).
